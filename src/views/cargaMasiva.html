Guía de Cargas Masivas

Antes de subir, descarga el reporte para ver la estructura; luego desbloquea con el candado, selecciona el archivo y finalmente súbelo.

Orden recomendado: Secciones/Clases → Espacios → Asignaturas → Profesores → Disponibilidades.

  • Descarga el reporte para ver la estructura y columnas esperadas.
  • Desbloquea la tarjeta con el candado (verifica/limpia si aplica).
  • Selecciona el archivo .xlsx con el botón correspondiente.
  • Pulsa "Subir Archivo" para cargar los datos.

Carga de Secciones/Clases

Importa o exporta Secciones/Clases. Descarga primero el reporte para ver columnas esperadas y sube un .xlsx sin fórmulas.

Descarga la lista actualizada de Secciones.

Carga de Espacios

Importa o exporta Espacios físicos. Trabaja con la plantilla descargada y usa .xlsx con encabezados simples.

Descarga la lista actualizada de Espacios.

Carga de Asignaturas

Importa o exporta Asignaturas según la plantilla. Valida que los nombres de grados y espacios coincidan con los cargados previamente.

Descarga la lista actualizada de Asignaturas. Columnas: Asignatura, Horas Semanales, Descripción, Duración Bloque Min, Duración Bloque Max, Tipo de Espacio Requerido, Grado.

Carga de Profesores

Importa o exporta Profesores. Usa la plantilla para evitar errores y mantén identificadores y asignaturas consistentes. Importante: no incluyas la columna "Usuario" al subir; el nombre de usuario se asigna automáticamente.

Descarga la lista actualizada de profesores. Si el reporte incluye la columna "Usuario", elimínala antes de subir: el sistema la genera automáticamente.

Carga de Disponibilidades

Importa o exporta disponibilidades de profesores. Sigue la estructura de hojas indicada en la plantilla.

Descarga un Excel con la hoja: DisponibilidadProfesor.
